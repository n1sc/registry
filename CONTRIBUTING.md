# Contributing

Thanks for publishing a module for Neutron.

## What a pull request should contain

- One new file: `packages/<name>.toml`.
- Nothing else. `index.json` is generated by CI, and changes to the scripts
  belong in a separate pull request.

## Package file

```toml
[package]
name = "json"
description = "JSON parsing and encoding"
repo = "https://github.com/you/ntsc-json"
license = "MIT"
keywords = ["json", "serialization"]
```

| Field         | Required | Rules                                                        |
| ------------- | -------- | ------------------------------------------------------------ |
| `name`        | yes      | Matches the file name; `[a-z0-9][a-z0-9._-]*`                |
| `description` | yes      | One sentence, at most 200 characters                          |
| `repo`        | yes      | `https://`, `http://`, `ssh://` or `git@` URL                |
| `license`     | no       | SPDX identifier, e.g. `MIT` or `Apache-2.0`                  |
| `keywords`    | no       | List of lowercase strings used by `ntsc pkg search`          |
| `versions`    | no       | Explicit versions; defaults to the repository's git tags     |

## Checks

```bash
python3 scripts/build_index.py --validate-only
```

CI runs the same command, plus `--check` once the index has been rebuilt.

## Review criteria

- The package builds with a released `ntsc` and its `neutron.toml` names an
  entry module that exists.
- The repository is public and the licence allows redistribution.
- The description says what the module does, not what it is called.

Names are first come, first served. A package that is abandoned or broken may
be removed; open an issue if that happens to you.
